# 隔离区

`fetch_oi.py` 的四项校验（见该文件 `validate()`）任一命中时，坏数据与原始 PDF
落在这里，`data/oi.json` 保持上一份可用数据不被覆盖。

```
oi-YYYY-MM-DD.json        被拒的解析结果 + 失败原因 + 隔离时间
section62-YYYY-MM-DD.pdf  当次的原始 PDF
```

文件名以 PDF 自身的 Trade Date 为键，同一份坏文件反复抓到时覆盖而非堆积。

**这个目录要提交进仓库。** CME 只提供 `current` 当日文件、没有历史归档，
坏数据错过就永久拿不回来，事后排查完全依赖这里的快照。

## 校验项

| | 检查 | 说明 |
|---|---|---|
| a | Trade Date | PDF 自身日期是否落在可接受交易日区间内（最强，优先） |
| b | 逐字段比对 | 是否与上一份结算价、持仓分毫不差 |
| c | 合约数量 | 相对上一份的变化是否超出 ±3（PDF 改版） |
| d | 主力月持仓 | 是否为 0 或 null |

排查完成后手工删除对应文件即可。
